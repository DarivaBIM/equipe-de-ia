# Depois da web: conhecer a pasta local

Esta extensão é demonstrada pelo apresentador em ambiente já preparado. Não instale clientes,
Git ou sincronizadores durante os 12–15 minutos da atividade individual.

Na web, você forneceu material e copiou resultados. Em um cliente local autorizado, o agente
pode trabalhar nos arquivos da pasta que você abriu, conforme as permissões disponíveis.
Arquivo local não significa processamento offline nem autorização para enviar qualquer dado.

## Os mesmos papéis, com arquivos

| Na trilha web | Na casa local preservada |
|---|---|
| Acordos e ficha do papel | regras-comuns.md e papeis/ |
| Produção — documentos | papel Gestão; produtos em gestao/ |
| Conferência — fontes | papel Pesquisa e Verificação; parecer em pesquisa/ |
| Registro de continuidade | estado-atual.md e handoff.md |
| Material entregue à conversa | fontes/ e arquivos lidos no escopo autorizado |
| Orientação do cliente | CLAUDE.md para Claude Code; AGENTS.md para Codex |

A versão web produz uma pauta curta. O percurso local original produz relatório e pauta em
formatos próprios. Não aplique o verificador local à saída web como se fosse o mesmo contrato.

## Percurso preparado do apresentador

1. Siga o [README local](../README.md), copiando a oficina para uma pasta própria.
2. Abra **somente a casa didática**, primeiro no Claude Code e depois no Codex.
3. Mostre as entradas CLAUDE.md e AGENTS.md apontando às regras comuns e aos papéis.
4. Use os prompts locais P00/P02/P03: Claude Code produz; Codex confere a versão e as fontes.
5. O autor corrige; outro cliente revê a alteração. Registre autoria, resultado e pendências.
6. Mostre estado e handoff e peça a leitura em outra conversa. Não afirme que o arquivo disparou essa conversa.

O caminho canônico do kit local é:

```text
C:\IA-Professor\oficina-feelt\casa
```

Quem usa Documentos substitui o início de todos os caminhos. Gerência propõe organização e
mudanças das regras da casa; o professor autoriza. A ficha de gerente não dá poder técnico sobre
contas, permissões ou configurações globais.

## Outro computador e sincronização

O [guia de sincronização](../sincronizacao/GUIA-SINCRONIZACAO.md) é uma extensão opcional, com
scripts preservados. Na aula, sua prova é uma **simulação local**, identificada como tal.
Os aplicativos e acessos são preparados em cada máquina; não viajam com os arquivos.

O mecanismo didático transporta commits revisados de caminhos permitidos. Quinze minutos é
intervalo entre tentativas, não garantia de chegada. A lista atual não inclui os arquivos da
trilha web nem seus prompts: copie esse material didático separadamente quando necessário.
Incluir um novo conteúdo na sincronização exige revisar o escopo; não copie a memória privada
inteira do usuário nem altere a lista durante esta demonstração.
