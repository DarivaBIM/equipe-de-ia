# Textos para copiar

Abra o arquivo, selecione todo o texto e copie para a conversa indicada. Na visualização do
GitHub, pode abrir o texto bruto (Raw) se isso facilitar a seleção. Não copie a navegação da página.
Estes textos derivam de equipe.md, fontes-do-caso.md e dos blocos de prompts; não são outra fonte de regras.

**Com anexos — começo principal:** anexe equipe.md e fontes-do-caso.md e use
[P00-ANEXOS, com preparação curta](P00-ANEXOS.txt). Selecione o papel no campo indicado.
Os três P00 completos abaixo são o fallback por colagem, com as fontes já incluídas.

1. [P00 Produção](P00-PRODUCAO.txt), pronto com acordos e fontes, para o ChatGPT.
2. [P10 Produzir](P10.txt), na mesma conversa.
3. [P00 Conferência](P00-CONFERENCIA.txt), pronto com acordos e fontes, para o Claude.
4. [P20 Conferir](P20.txt), preenchendo o autor observado e o texto integral de V1.
5. [P21 Avaliar o parecer](P21.txt), apoio à leitura humana.
6. [P22 Autor corrige](P22.txt) **ou** [P23 Revisor passa a autor](P23.txt), após decisão humana.
7. [P24 Rever V2](P24.txt), no cliente diferente do autor de V2.
8. [P30 Decidir e registrar](P30.txt) e [P40 Retomar](P40.txt), com documentos e versões corretos.

**Formas alternativas de pedir:** [E01](E01.txt), [E02](E02.txt), [E03](E03.txt),
[E04 mensagem 1](E04-1.txt) e [mensagem 2](E04-2.txt), [E05 Direção Aberta](E05.txt),
[E06 Corpo padrão](E06.txt). Não é necessário executar todas na prática individual.

**Gerência:** [preparação](P00-GERENCIA.txt) e [G01 Organizar frentes](G01.txt).

O texto do prompt não preenche por você a decisão humana. Não envie placeholders vazios nem
afirme que um produto foi revisado antes de conferir o parecer da versão correspondente.

Para uso offline, o ZIP do repositório contém esta pasta e as fontes sintéticas. Você pode ler
e conferir o exemplo preparado sem conexão; conversar com um serviço web depende de acesso.
