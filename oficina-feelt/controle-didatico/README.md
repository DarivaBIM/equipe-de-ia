# Controle preparado

Use este arquivo somente depois da tentativa real, ou quando não houver acesso a um cliente.
Ele contém **dois erros intencionais na linha CAL-02**: a situação foi promovida a concluída
e uma data sem apoio foi criada. O código e as referências existem, mas o conteúdo contradiz
F1 item 2 e F3. Referenciar uma fonte não prova que ela sustenta a afirmação.

Não conte esta análise como revisão da geração ao vivo. O professor deve dizer que este
é um controle didático preparado. Nenhum participante precisa provocar erro no modelo.

Para analisar em um agente, autorize explicitamente a leitura deste arquivo fora de `casa`
e mantenha as fontes reais do exercício como referência. Não copie o controle por cima de
`gestao/relatorio-rascunho.md`.
